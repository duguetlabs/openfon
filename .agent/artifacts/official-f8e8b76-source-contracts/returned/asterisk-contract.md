## Direct internal invocation versus public ingress

A binding caller invoking AsteriskCall directly has already contacted/possibly allocated the DO; therefore direct-internal refusal cannot promise zero DO allocation. Its malformed protocol/path can fail before admission, while a valid-shaped request against an already-disabled owner still fails the admission helper before DB/storage/reservation/session work. Exporting a DO class does not register /media as a public proxy, and the public caller cannot supply its own trusted admission version through the fresh handoff.

Privileged code can invoke generic CALL_SESSION directly without traversing Asterisk admission, or unit fixtures can call TypeScript-private install methods. Neither is the registered public PBX route. Such calls cannot establish the report's authenticated-public-disabled attack. The source inspection makes no guarantee against malicious code with a Durable Object binding.

## Mid-flight disable and retained limits

- Global ASTERISK_ENABLED is an environment binding, default false in wrangler.jsonc:32; inspected production source reads it and has no runtime setter. Source alone does not prove a deployment change mutates an in-flight owner env object, atomically updates all isolates, drains old versions or immediately revokes every existing socket.
- If an owner sees false at its initial admission check, it stops before reservation. If work was admitted while true and a false value is observed only later (for example by a different deployed owner configuration, or explicitly mutable test env), some authentication/DB/DO work may already exist. There is no second env predicate inside the D1 INSERT or immediately before CALL_SESSION dispatch. install can cancel after reservation/session allocation; the admitted row is retained and daily quota is not refunded. This is a narrower in-flight boundary, not repeated disabled-at-entry acceptance.
- Per-route asterisk_routes.enabled is distinct. SELECT/post-KDF/advisory/owner checks and the INSERT predicate observe it before reservation. A route change after a successful INSERT is not retroactive cancellation: install and tick check the global env flag, not a fresh per-route row. Shared CallSession loadCall requires active state but does not reread the route's enable bit. Do not claim instant per-route revocation of an already-admitted conversation.
- Established owner tick observes global disable in the ordinary no-cleanup branch. It closes the adapter and projects release/failure, with an ordinarily rearmed30-second alarm; no hard wall-clock bound under scheduling or storage/D1 failure is asserted. Existing cleanup waits its future deadline before retirement. finish arms recovery before D1, preserves earlier failure metadata, marks carrier release, then retains a60-second cleanup opportunity for session finalization. - Both auth and ingress budgets remain separate constant-size per-isolate counters:16starts,2/second refill,4in-flight; starts are not refunded. Ingress holds through awaited auth/preflight/owner work. It is neither a cross-isolate/global bound nor a cancellation guarantee; direct binding callers do not use the public ingress lease.
